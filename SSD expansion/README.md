# Expand the Prophet X SSD

The PX SSD conveniently includes a set of QNX tools. We'll clone the entire drive, extract those tools, create a bootable image, use a VM to create the QNX filesystem on the new SSD, and finally copy across the samples and bootloader from the old drive. A Crucial M500 480 GB replacement has been confirmed working. No firmware update required; this is a separate hardware/storage procedure.
