Create patched firmware

Select your original PxUpdate_V2.2.2.0.0.bin to create PxUpdate_V2.2.2.2.2.bin, with all the fixes listed below.

All firmware processing stays on your computer. Your firmware is never uploaded. There are no analytics, external scripts or server-side patching.

Before installing, read the recovery guide and back up your SSD. Install at your own risk and keep generated firmware private.


Only the exact stock 2.2.2.0.0 image (3,099,064 bytes) is accepted. The contents are verified by SHA-256; renaming another file will not work.

Included fixes in 2.2.2.2.2
  • Voice steal bug: Fixed bug where amp envelope attack was ignored on voice steal, causing a harsh click when sample start was set on a non-zero crossing.
  • SysEx bug: Fixed bug where the synth ignored sysex when set to receive midi on any channel but 2 or omni.
  • Window scroll clicks: Reduced clicking when scrolling Start or End across loop boundaries, particularly with short windows.
  • Sample-end fade: Added a 5 ms fade on sample end, including reverse playback. Eliminates clicks caused by stopping at non-zero crossings when looping is disabled.
  • Center moves window: Center can now move the Start/End window through the sample instead of being constrained inside it.
  • Start/End push Center: Allows sample Start and End values to push the Center position instead of being blocked by it.
  • Window bug: Fixed bug where editing both sample layers together could allow Start to move past End and leave the sample window in an invalid state.
  • Tail retrigger bug: Fixed bug where increasing End after a held sample had already finished could unexpectedly retrigger the newly exposed tail.
  • Loop sync divisions: Previously minimum loop sync was 1/16. This has been reduced to allow 1/32 and 1/64.
  • Preset browsing lag: Reduced screen lag when scrolling presets.
  • Encoder acceleration fix: Removed acceleration from all encoders except for sample controls.
  • Stretch velocity layer: Enabling stretch while a note is held now selects the held velocity layer in addition to its note, and the layer can be changed using the menu as expected. Previously stretch would always choose the highest layer with no way of changing it.
  • Type encoder tweak: Moving the 'type' encoder now starts instruments at entry number 2 if it exists instead of the always-blank entry 1, making it easier to see which types are populated with instrument samples when scrolling.

What the patcher verifies

Exact stock identity, container framing and checksums, all guarded patch writes, changed-byte ownership, the unchanged FPGA record, ELF sections and load mappings, all 910 unwind-index targets, revision headers and gates, and the exact final length and SHA-256.

The browser uses a fixed guarded-write recipe generated from the direct Python builder. Matching stock bytes are copied from your input. See the browser implementation and verification notes.

Install the patched firmware

  1. Keep a verified SSD backup and read the recovery guide linked above.
  2. Obtain the original Sequential 2.2.2.0.0 firmware, select it above, then create and download the verified update.
  3. Copy the update to your USB update drive. Keep its exact name: PxUpdate_V2.2.2.2.2.bin.
  4. Independently verify the size and SHA-256 of the copy on the USB drive using the values below.
  5. Follow Sequential’s Prophet X update procedure.

Expected output: 3,187,784 bytes

SSD expansion

SSD expansion is a separate procedure and does not require patched firmware. Follow the existing SSD expansion guide for backups, maintenance-image creation, migration and verification.

The tested migration procedure uses Linux and a QNX virtual machine. Maintenance-image creation uses the repository’s Python tools; it is not available in this browser patcher.
