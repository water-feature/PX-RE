# Direct firmware builder

This folder contains the cross-platform builder used by [patch.py](../patch.py) to generate the combined 2.2.2.2.2 update from factory firmware.

Follow the [patching instructions in the main README](../../README.md#patching-the-firmware-using-the-supplied-tool) to run it. You need Python 3.11 or newer.

For the code layout, validation checks, object provenance and cache maintenance, see [IMPLEMENTATION.md](IMPLEMENTATION.md).
